# ♻️ Сортировщик — игра по сортировке мусора

Браузерная игра, в которой нужно перетаскивать мусор в баки правильного цвета. Игра учит раздельному сбору отходов, не требует установки и внешних библиотек, работает на компьютере и на телефоне.

**[▶ Играть](https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/)**

## Возможности

- **Drag & Drop.** Предметы перетаскиваются мышью или пальцем, поддерживаются touch-экраны.
- **Комбо.** Правильные ответы подряд увеличивают множитель очков.
- **Уровни.** Новые виды мусора и баки открываются по мере роста счёта.
- **Подсказки.** При ошибке игра показывает, в какой бак нужно было бросить предмет. В меню есть «Памятка» с правилами для каждого бака.
- **Эффекты.** Частицы, анимации и звуки, сгенерированные через Web Audio API. Звук можно выключить.
- **Рекорды.** Топ-10 результатов хранится в браузере с подробной статистикой.

## Баки

| Бак | Что сюда идёт | Что нельзя |
|---|---|---|
| 🔵 Синий — макулатура | газеты, книги, журналы, упаковка из-под обуви, гофрокартон | жирная и промасленная бумага, бумага с остатками еды |
| 🟡 Жёлтый — пластик и металл | пластиковые бутылки, пакеты, контейнеры, алюминиевые банки, крышки, упаковка от йогуртов, тетрапаки | грязная упаковка (нужно хотя бы очистить от остатков) |
| 🟤 Коричневый — органика | кожура, остатки фруктов и овощей, чайные пакетики, кофейная гуща, испорченные продукты | |
| 🟢 Зелёный — стекло | бутылки, банки, осколки (без крышек и пробок, промытые) | |
| 🔴 Красный — опасные отходы | батарейки, лампы, электроника, химикаты, лекарства | |
| ⚫ Чёрный — несортируемые отходы | загрязнённые материалы, старые губки, использованные салфетки, строительный мусор, жирная бумага | |

Несколько фактов из игры: сухая чистая бумага перерабатывается много раз и сокращает вырубку деревьев, стекло перерабатывается бесконечно без потери качества, а органика составляет до 40% всего мусора и превращается в компост.

## Уровни

| Уровень | Очки | Что открывается |
|---|---|---|
| 1 | 0+ | Синий, жёлтый и коричневый баки |
| 2 | 50+ | Зелёный бак (стекло) |
| 3 | 150+ | Красный бак (опасные отходы: батарейки, лампы, электроника, химикаты, лекарства) |
| 4 | 300+ | Чёрный бак (несортируемые отходы) |

## Правила и очки

| Событие | Очки |
|---|---|
| Правильный ответ | +10 × множитель комбо |
| Неправильный ответ | −5 и сброс комбо |
| Бак заполнен (6 предметов) | +20 |
| Больше 12 предметов на поле | −2 в секунду |

Множители комбо: **×2** при 4+ подряд, **×3** при 7+, **×5** при 10+.

Если на поле накопится 18 предметов, игра заканчивается. Счёт не опускается ниже нуля.

## Рекорды и статистика

В конце партии можно ввести имя и сохранить результат. В таблице хранятся 10 лучших игр: очки, лучшее комбо, точность и время игры. Данные лежат в `localStorage`, поэтому они остаются только в том браузере, где вы играли.

## Технологии

- HTML5
- CSS3: анимации, градиенты, адаптивная вёрстка
- Vanilla JavaScript без зависимостей
- Web Audio API
- localStorage

Вся игра находится в одном файле `index.html`.

## Запуск

**Локально.** Скачайте `index.html` и откройте его в браузере.

**На GitHub Pages.**
1. Загрузите `index.html` в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите ветку `main` и папку `/ (root)`, затем сохраните.
4. Через минуту игра станет доступна по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.
